## Why this exists

"AI RCA" is only a feature if its accuracy is measured. This scores an analyzer
against labelled incidents whose true root cause is known. The deterministic
(rule-based) analyzer is scored in CI with no API key or network, and the build
fails if accuracy regresses. LLM providers implement the same `Analyzer`
interface and can be scored with the same harness when a key is present.

## Known limitation (honest headroom)

The `hidden-root-undeclared-dependency` fixture is expected to **miss**: the true
root cause sits behind a dependency edge that was never declared, so the
deterministic graph walk blames the nearest declared cause. This is exactly the
gap an LLM narrative that reads the alert messages can close — the reason the
LLM providers exist above the rule-based fallback. Keeping the miss in the set is
what makes the headline number trustworthy rather than a fixture designed to pass.
